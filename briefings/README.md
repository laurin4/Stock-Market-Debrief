# Morning briefings

`morning-market-briefing.html` is the daily note. It is overwritten each run. Open it in a browser. After you pull this repository, attach that file in Gmail if you want to share it.

The page is self-contained: styles are in the file, and figures are sourced in the Sources section. The VWRA line in francs is a translation of the London dollar listing (VWRA) using the dollar/franc rate. It is not a Swiss-exchange price. Watch levels used in the note are 140 and 135 francs.
